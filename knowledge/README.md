# Ken Interlinking Knowledge Base

This directory contains durable product and editorial knowledge that implementation agents must use
alongside the governing specifications in the repository root.

Knowledge-base documents describe **why the product should behave a certain way**. They do not
silently override frozen contracts, ADRs, safety controls, or production permissions. If a knowledge
document conflicts with an ADR or a governing specification, stop and surface the conflict.
