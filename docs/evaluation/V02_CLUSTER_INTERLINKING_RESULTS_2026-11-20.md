## Eligibility method

Every new draft uses the public Market Trajectory forecast paragraph. It states a factual
cross-geography comparison using forecast values or growth rates supported by both reports. The
full destination market name is the anchor. Market Overview and Related Reports are not used.

Each source placement was confirmed in public rendered text and checked for an existing link to
the destination. The drafts remain shadow-only until a human approves them, the CMS dry-run passes
and one rendered public anchor is verified.

## Blocked direction

Mexico Cargo Security to Latin America Cargo Security is blocked. The Mexico report has no public
explanatory paragraph that can carry a useful contextual comparison. The existing Latin America
to Mexico link remains live and verified. Exact market membership does not override a missing
visible placement.
