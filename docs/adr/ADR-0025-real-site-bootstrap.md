- **Status:** Accepted and implemented, 2026-10-29.
- **Decision owner:** the project owner, in the session of 2026-10-29.
- **Resolves:** NEXT_STEPS items 1, 2a/2b (approval to crawl), 5 (partly), 7, 15 (enablement) and 17 (approval).
- **Authority:** CLAUDE.md — crawling a domain, enabling a paid-or-external service and a live deployment are all ASK actions; the owner answered each in writing.

## What was built

1. **A rendered export, not a raw crawl.** Pages were fetched with the Playwright MCP server
   (ADR-0024) and written as the documented `ken-inventory-export` v1 JSONL. The live site streams
   content into hidden segments (commit `c5aebb5`), so the export holds the *rendered* `<main>`
   (or the `<body>` minus header, footer and nav where a page has no `<main>`), with scripts,
   styles and SVG removed. `robots.txt` was read first and every disallowed path skipped.
2. **A deterministic stratified sample**, because the sitemaps list about 9,000 pages and the
   approved cap was 500: evenly spaced picks per sitemap — home 1, static 14, brand comparison 9,
   PoV 53, case studies 55, articles 80, benchmarks 70, surveys 70, reports 148. Result: 498 pages
   (one navigation timeout, one 404 that the sitemap still lists).
3. **A separate database, `ken_real500`**, so synthetic demo data (`ken_interlink`) is never mixed
   with real content.
4. **`policies/taxonomy/taxonomy.v2.yaml`**, `status: proposed`, generated by
   `evals/intelligence/derive_taxonomy.py`: 46 geographies and 202 markets in 14 industries from URL
   slugs; real page-type families; legal-page protection. It is **not** the default
   (`KEN_TAXONOMY_PATH` still names v1) until the owner promotes it.

## What this is not

- **Not a full inventory.** It is a 6 % sample (498 of about 9,000). Coverage statistics and
  link-graph measurements are properties of the sample, not of the site.
- **Not Ken's official taxonomy.** Markets come from report slugs, so articles, surveys and case
  studies rarely get a market tag (5 %–23 % in the first analysis, against 72 % for reports and
  benchmarks). The company/product gazetteer is empty: it needs Ken's data.
- **Not a live deployment.** Approving the beacon does not enable it: the CMS write path is still
  the mock, and the legal consent question in NEXT_STEPS item 17 (ePrivacy, GDPR, India's DPDP Act)
  remains open for whoever deploys it.

## Consequences

- The export and crawl plan live under `/data/` (git-ignored: public but large and regenerable).
- Re-running the crawl needs the same approval limits; the plan is deterministic, so a re-run
  fetches the same URLs.
- The `anchor` and country-pairing behaviour on real text differs from the synthetic corpus: see
  PHASE_8_REPORT.md for what the first real run showed.
