# ADR-0006 — Minimal Phase 0 schema: the `events` table only

- **Status:** Accepted (user decision, 2026-10-13)
- **Phase:** 0

## Context

TRD.md §5 names 19 required domain tables but specifies **no columns** for any of them.

## Decision

Migration `0001_initial_events` creates exactly one table, `events`, column-for-column with
`ken_contracts.events.EventEnvelope`. It runs **no** `CREATE EXTENSION` and creates **no** vector
column (ADR-0003).

| Column | Type | Notes |
|---|---|---|
| `id` | bigint identity PK | insertion order, keyset pagination |
| `event_id` | uuid, unique | deduplication; idempotent append |
| `event_name` | text | validated by the Pydantic `EventName` enum, **not** a DB enum, so the vocabulary grows without a migration |
| `event_version` | int, ≥ 1 | payload schema version |
| `occurred_at` | timestamptz | |
| `emitted_by` | text | audit: which component wrote it |
| `subject_type`, `subject_id` | text, nullable | "every event for page X" is an indexed query, not a JSON probe |
| `payload` | jsonb | |
| `correlation_id` | uuid, nullable | ties events to a request or agent run |
| `created_at` | timestamptz | append-only: no `updated_at` |

## Why one table rather than nineteen

- Creating all 19 means inventing roughly 200 columns with no specification, guaranteeing churn in
  `0002+` once the real crawler (Phase 1) and scorer (Phase 3) define their shapes.
- 18 of those tables would have no test coverage.
- `page_embeddings` would need `vector`, which the native database does not have.
- `events` is fully specified by TRD §15, append-only (only ever extended, never reshaped), and gives
  the worker something real and harmless to write.

## Why the envelope is richer than TRD §15 strictly requires

Because this table is created in Phase 0, the envelope becomes DDL immediately — and an append-only
audit log is the worst possible table to retrofit with a backfill. The architecture review of the W0
freeze required `event_id`, `event_version`, `emitted_by` and the subject reference before the
migration was written.
